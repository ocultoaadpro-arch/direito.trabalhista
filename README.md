## 🚀 Funcionalidades
- **Gatilho Inteligente de Lead:** Modal de qualificação rápida (Nome, WhatsApp, Assunto) disparado apenas quando o visitante chega ao final absoluto da página ou clica em um botão de ação.
- **Integração WhatsApp:** Redirecionamento formatado direto para o WhatsApp do escritório com o assunto pré-selecionado pelo cliente.
- **Micro-Painel Administrativo:** Gestão interna de leads com status e exportação (`admin.html`).
- **Versão Lovable / React:** Componente nativo em React + Tailwind disponível em `lovable-Index.tsx`.

## 📁 Estrutura de Arquivos
- `index.html` — Página principal de conversão.
- `styles.css` — Sistema de design responsivo, animações e efeitos de luz.
- `script.js` — Lógica de conversão, tracking, modais e scroll triggers.
- `admin.html` — Painel do advogado para visualização de contatos.
- `assets/` — Imagens em alta resolução, fotografias da equipe e logotipos oficiais.
- `lovable-Index.tsx` — Versão convertida para projetos Lovable / Vite / React.
